通过桌面右键菜单，快速切换 Windows 深色与浅色模式，切换效果与系统「设置」中的颜色模式选项一致。

### 本次更新

- 支持 Windows 11 新式桌面右键菜单。
- 两种菜单统一为一个动态选项，文字和图标随当前模式变化。
- 支持菜单个性化的系统首次安装默认一级显示，后续升级保留你的选择。
- 没有主窗口、托盘图标或开机启动项。
- 安装无需手动导入证书，无需额外安装 .NET 或 Visual C++ 运行库。
- 支持覆盖安装，并修复卸载后遗留空安装目录的问题。
- 增加命令行 `toggle` 参数。

### 安装与使用

下载并双击下方的 **ThemeSwitcherSetup.exe**，允许 Windows 的管理员权限提示，完成安装后即可在桌面空白处右键切换。

已有版本可直接覆盖安装。适用于原生 x64 的 Windows 10 和 Windows 11；新式菜单的位置取决于系统版本及个人设置。

需要移除时，可通过 Windows「已安装的应用」卸载，当前颜色模式保持不变。
