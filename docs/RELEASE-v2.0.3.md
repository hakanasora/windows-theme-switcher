Windows Theme Switcher 2.0.3 主要改进菜单组件和安装流程的可靠性，日常使用方式保持不变。

### 本次更新

- 改进异常安装状态和菜单偏好的处理。
- 修复菜单组件的并发边界，完善异常参数检查。
- 增强旧组件清理、目录保护和失败后重试能力。
- 保持无主界面、无托盘、无独立常驻服务的使用方式。

### 安装与升级

下载并运行下方的 `ThemeSwitcherSetup.exe`。已有用户可以直接覆盖安装，无需先卸载旧版；升级保留已有的一级菜单显示选择。

本版本面向原生 x64 Windows。新式桌面菜单需要 Windows 11 22H2 及以上；其他受支持系统使用传统菜单。在支持菜单个性化的 Windows 版本上，也可通过系统设置调整菜单显示位置。

不需要手动导入开发证书。无签名身份包部署仍受 Windows 版本和设备策略影响。
